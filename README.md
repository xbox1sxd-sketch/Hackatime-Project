## Incremental Space Shooter

Incremental Space Shooter is an incremental arcade game where you control a spaceship with your mouse, shoot falling asteroids, earn money, and upgrade your ship. The goal is to destroy asteroids, earn enough money to purchase upgrades, and become more powerful as you progress.

This game was made for Hack Club Terra.

Play the game: https://bluecreekdev.itch.io/incremental-space-shooter

## How I Built It

I built this game using Godot 4 and GDScript. I used Godot's game engine to create the gameplay, handle mouse-based movement and shooting, spawn asteroids, track money and health, and implement the upgrade system.

I also used ChatGPT as a learning and debugging tool when I was stuck on errors or confused about certain programming concepts. I used it to help me understand problems and work through solutions. I also used it to write some code for me when I was at a complete loss for what to do.

## How to Play

You can play the game directly in your browser or download the executable from the itch.io page:

https://bluecreekdev.itch.io/incremental-space-shooter
Controls

Move your mouse to fly your spaceship

Left click to shoot

Press esc to release the mouse

## How to Run from Source

Install godot 4

Clone or download this repo.

Open godot 4.8 and click import

Select the project.godot from the repo you cloned/downloaded

Open the project and press f5 to play the game.
