Incremental space shooter. 
 A small incremental game where you fly a ship with the mouse, shoot falling asteroids, and upgrade your ship.
 Made for Hack Club Terra.
 Play it: https://bluecreekdev.itch.io/incremental-space-shooter 
 How I built it Built with Godot 4 and GDScript.
 
 How to run: Install Godot 4. Clone or download this repo. In Godot, click Import, select project.godot then run the game.  Controls: move the mouse to fly, left click to shoot, Esc to release the mouse.
 Or go to https://bluecreekdev.itch.io/incremental-space-shooter to download the exe or play the web version.

I have used AI (chatgpt) when I was unable to solve errors or was confused about something.
